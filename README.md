# Мандала

Задания на каждый день месяца: продажи, сервисы, Радар, нейронки, спорт и английский.
Оплаты, воронка, вес и тренировки записываются здесь же, из них строится аналитика.
Статический сайт для GitHub Pages: без сервера и сборки.

## Запуск

1. Загрузи **содержимое** этой папки в корень репозитория (index.html должен лежать в корне).
   Старые файлы прежней версии можно удалить: plan.js, plan-data.js, daily.js, seed.js, SALES.html, SETUP.html, firestore.rules.
2. Settings → Pages → Deploy from a branch → ветка main, папка /(root).
3. Открой сайт, выбери дату первого дня и нажми «Начать».

Локально сайт тоже открывается двойным щелчком по index.html.

## Разделы

- **Сегодня** — задания дня. У каждого: время, шаги, критерий готовности, поле для ответа,
  кнопки «Завершить задание» и «Скопировать запрос для Claude». В тренировках — поля «кг» и «повторы».
  Внизу — вес, сон и самочувствие.
- **Месяц** — 30 дней сеткой, по клику открывается день.
- **Продажи** — оплаты и цифры дня по каналам: касания, ответы, пробные поставки.
- **Спорт** — вес тела, самочувствие, прогресс по каждому упражнению.
- **Аналитика** — оплаты нарастающим итогом, темп, задания по дням и направлениям, каналы, все месяцы.
- **Данные** — отчёт месяца, следующий месяц, резервная копия.

## Следующий месяц

1. В «Данных» заполни четыре поля итогов и нажми «Скачать отчёт месяца» — получишь `mandala-report-month-01.json`.
2. Отправь файл в чат Claude и попроси составить следующий месяц. Формат плана описан внутри отчёта (поле `nextPlanFormat`).
3. Полученный `month-02.json` загрузи на GitHub в папку `months`. Сайт сам проверяет month-02.json, month-03.json и дальше.
   Номера должны идти подряд.
4. Когда первый месяц закончится, сайт предложит начать второй. Первый остаётся в «Аналитике» и во вкладках месяцев.

Если нужно попробовать план без GitHub — «Данные» → «Загрузить план только в этот браузер».

## Где лежат данные

Отметки, ответы, оплаты и вес хранятся в браузере (localStorage), в репозиторий они не попадают.
Чтобы перенести их на телефон: «Данные» → «Скачать копию», на телефоне — «Восстановить из копии».
Очистка данных браузера стирает записи, поэтому раз в неделю скачивай копию.

Данные прежней версии сайта (матрица 9×9) не переносятся: они остаются в браузере под старым ключом и ничему не мешают.
Синхронизации через Firebase в этой версии нет.

## Файлы

- `index.html`, `styles.css`, `app.js` — интерфейс.
- `core.js` — проверка планов, расчёты, отчёт.
- `months/month-01.js` — первый месяц; рядом кладутся `month-02.json` и следующие.
- `tests/core.test.cjs` — проверки расчётов. Запуск: `node --test tests/core.test.cjs`.
